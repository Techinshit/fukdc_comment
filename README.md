# fukdc_comment

This is a Tampermonkey script and requires the Tampermonkey extension to be installed prior to use.
It operates on the DCInside website, automatically disabling the image comment box and providing a separate, integrated UI at the bottom of the page.

해당 스크립트는 템퍼몽키 스크립트로 템퍼몽키 설치 후 작동 가능합니다.
DCInside 홈페이지에서 작동하며, 이미지 댓글창을 자동으로 off하고 하단에 별도의 통합 UI를 제공합니다.

PC
[스크립트 설치(Install Script)](https://github.com/Techinshit/fukdc_comment/raw/refs/heads/main/FukDCInside.user.js)

Mobile
*   **AdGuard 사용자:**
    1. 위 '설치하기' 버튼을 꾹 눌러 '링크 주소 복사' 혹은 아래의 링크를 복사
    2. AdGuard 앱 설정 > 필터링 > 확장 > 확장 프로그램 추가 > 'URL에서 추가'에 복사한 주소를 붙여넣기
https://github.com/Techinshit/fukdc_comment/raw/refs/heads/main/FukDCInside.user.js

*   **TamperMonkey 사용자:**
    1. 위 '설치하기' 버튼을 꾹 눌러 '링크 주소 복사' 혹은 아래의 링크를 복사
    2. TamperMonkey > 유저 스크립트 추가 > 'URL에서 추가'에 복사한 주소를 붙여넣기
