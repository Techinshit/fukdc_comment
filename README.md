# fukdc_comment

This is a Tampermonkey script and requires the Tampermonkey extension to be installed prior to use.
It operates on the DCInside website, automatically disabling the image comment box and providing a separate, integrated UI at the bottom of the page.

해당 스크립트는 템퍼몽키 스크립트로 템퍼몽키 설치 후 작동 가능합니다.
DCInside 홈페이지에서 작동하며, 이미지 댓글창을 자동으로 off하고 하단에 별도의 통합 UI를 제공합니다.
